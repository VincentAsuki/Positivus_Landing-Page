# Positivus Landing Page

A static frontend implementation of a digital marketing agency landing page built with HTML and Tailwind CSS v4.

This project recreates a modern agency homepage design featuring service sections, case studies, team profiles, testimonials, contact form, and footer subscription area.

---

## Built With

* HTML5
* Tailwind CSS v4
* Google Fonts

---

## Features

* Hero section
* Services section
* Case studies
* Working process layout
* Team section
* Testimonials section
* Contact form UI
* Footer newsletter area
